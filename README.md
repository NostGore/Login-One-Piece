# Interfaz de Acceso - Temática One Piece

Este repositorio contiene una interfaz de usuario para sistemas de autenticación, diseñada con una estética inspirada en la serie One Piece. El objetivo principal es proporcionar una experiencia visualmente atractiva y funcional tanto para el inicio de sesión como para el registro de nuevos usuarios.

## Componentes del Proyecto

El desarrollo se divide en tres pilares fundamentales que garantizan el rendimiento y la estética de la aplicación:

1. **Estructura (HTML):** Implementada en `login.html`, utiliza etiquetas semánticas para asegurar la accesibilidad y una jerarquía de contenido clara.
2. **Estilo (CSS):** Gestionado a través de `style.css`, incluye efectos de glassmorphism, animaciones de pulso y un sistema de capas para el fondo (vignette, grain, overlay).
3. **Interactividad (JS):** Controlada por `script.js`, maneja el cambio de pestañas entre formularios y la renderización de efectos dinámicos como la lluvia en el fondo mediante la API de Canvas.

## Características Técnicas

- **Diseño Dual:** Sistema de pestañas integrado que permite alternar entre Login y Registro sin recargar la página.
- **Efectos Visuales:** Fondo dinámico con partículas de lluvia, texturizado de grano y sombreado periférico para mejorar el enfoque en el formulario.
- **Tipografía y Gráficos:** Uso de fuentes especializadas (Pirata One, Cinzel Decorative) y fuentes de iconos (Font Awesome) cargadas mediante CDN.
- **Adaptabilidad:** Interfaz optimizada para ofrecer una visualización consistente en diversos tamaños de pantalla.

## Implementación

Para visualizar el proyecto localmente, simplemente clone el repositorio y abra el archivo `login.html` en su navegador preferido. Es necesaria una conexión activa a internet para la carga correcta de los estilos y fuentes externos vinculados.

## Créditos

Desarrollado como una pieza de interfaz personalizada, integrando recursos de Google Fonts y Font Awesome para elevar la calidad visual del producto final.
